<div><h1 align="center">Refresco</h1></div>
<div><h2 align="center">Simple, lightweight and efficient Chromium based browser extension that automatically reloads any tab at a user-defined interval.</h2></div>
<div><p>Refresco is a simple, lightweight and efficient browser extension that automatically reloads any browser tab at a user-defined interval. Customize the refresh rate in seconds to keep your tabs up to date — perfect for monitoring dashboards, live data pages, or time-sensitive content. The extension runs quietly in the background and ensures you always have the latest information without manual effort. Designed for performance and simplicity, it’s a must-have tool for anyone who values real-time updates and streamlined browsing.</p></div>
